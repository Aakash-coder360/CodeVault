# 🛡️ CodeVault

**Git Command Based Source Code Management with Automated CI/CD Deployment on GitHub.**

## 🚀 Features
*   **Automated Version Control:** Tracks every change using Git.
*   **Continuous Integration:** Uses GitHub Actions to test code quality.
*   **Continuous Deployment:** Automatically deploys to GitHub Pages on every push to `main`.
*   **Professional UI:** A clean, dark-mode developer dashboard.

## 🛠️ Tech Stack
*   Git & GitHub
*   GitHub Actions (CI/CD)
*   GitHub Pages (Hosting)
*   HTML/CSS
